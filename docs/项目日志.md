# 项目日志

## 2026-07-30 新增「编程挑战」模块（十题闯关 / 积分游戏化）

### 功能概述
新增 C 端「编程挑战」菜单：挑战赛道内含 10 道关卡，逐关解锁；浏览器端执行测试用例判题，后端判定通关并计算星级、积分与解锁；提供积分排行榜与个人战绩统计。

### 数据库（schema.sql / data.sql，H2 内存库随启动初始化）
- `code_challenge` 挑战赛道表（标题/语言/难度/图标/主题色/关卡数/总积分/状态）
- `code_challenge_level` 关卡表（level_no 序号、题目描述、示例、提示、代码模板、测试用例 JSON、积分）
- `code_challenge_record` 用户赛道进度表（通关数/当前关卡/累计积分/星星/是否全通）
- `code_challenge_level_record` 用户关卡记录表（是否通关/星级/尝试次数/所得积分/最近代码）
- 种子数据：1 条「JavaScript 十题闯关」赛道 + 10 道关卡（两数之和 → 经典算法，循序渐进）

### 后端（Spring Boot 3 + MyBatis-Plus）
- 实体：`CodeChallenge` / `CodeChallengeLevel` / `CodeChallengeRecord` / `CodeChallengeLevelRecord`
- Mapper：对应 4 个 BaseMapper
- DTO/VO：`ChallengeSubmitDTO`；`ChallengeVO` / `ChallengeDetailVO` / `ChallengeLevelVO` / `ChallengeSubmitResultVO` / `ChallengeRankVO` / `ChallengeStatsVO`
- 服务：`CodeChallengeService` / `CodeChallengeServiceImpl`
  - 判分模式与代码题库一致：前端跑用例上报 total/passCount，后端判定通关
  - 星级：1 次通过 3 星，2-3 次 2 星，≥4 次 1 星（仅首通计星计分）
  - 积分：3 星满分 / 2 星 80% / 1 星 60%，首通积分同步累加到用户 `exp`
  - 解锁：提交时校验上一关已通关；详情接口按顺序计算 locked
  - 排行榜：按用户聚合积分（同分比星星），支持单赛道榜与总榜
- 控制器：`CodeChallengeController`（`/api/challenges`）
  - GET `/api/challenges`、`/{id}`、`/leaderboard` 匿名可读（SecurityConfig 放行，登录后附带个人进度）
  - POST `/{challengeId}/levels/{levelId}/submit`、GET `/my/stats` 需登录

### 前端（Vue 3 + TS + Pinia）
- `api/challenge.ts` + `api/types.ts` 新增 6 个 Challenge* 类型
- 路由：`/challenge`（列表，匿名可看）、`/challenge/:id`（闯关，需登录）
- `CTopNav.vue`：桌面端「学习工具」下拉与移动端菜单新增「编程挑战」（rocket 图标）
- `Challenge.vue`：我的战绩卡 + 赛道卡片（进度条/星星/积分/参与人数）+ 积分排行榜 + 玩法说明
- `ChallengePlay.vue`：关卡地图（锁定/通关/当前态 + 星级展示）+ 题目面板（示例/提示折叠）+ 代码编辑器（Tab 缩进/重置模板/恢复上次代码）+ 浏览器端判题 + 通关弹窗（星级/积分/下一关）
