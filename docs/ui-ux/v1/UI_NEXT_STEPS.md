## P0 — 补齐本轮 PARTIAL（按收益排序）

1. **笔记 / 聊天 / 学习路径的密集工具条**：仍有 12–13px 按钮（`/notes` 77 个 13px、`/chat` 32 个 13px、`/learning/paths` 30 个 12px）。建议先抽一个紧凑工具条容器（`--kf-toolbar-*`），统一 14px 文字 + 32px 热区，避免逐页改。
2. **沉浸式页面**：`/knowledge/reader`、`/knowledge/new`、笔记编辑器未实拍。建议按 1440/1280/1024 各补一轮，重点看阅读宽度（`--kb-content-reading` 72ch）与新页头是否冲突。
3. **其余普通页**：社区、代码练习、知识图谱、知识工作台、`/learning/today-plan`、管理后台其余子页。建议只做「共享基线回归」截图（不改页面 CSS），确认 28px 标题 / 图标基线 / 无溢出。
4. **AppCard 密度**：当前单列 16px padding + 2 行描述。若用户反馈应用中心列表过长，可在 ≥1280 改为双列（`minmax(320px,1fr)`），但需同时验证排序按钮与拖拽。

## P1 — 验证与流程

5. **建立改前基线**：下一轮开始前先跑一次截图脚本并存 `screenshots/before/`，再改代码，形成真正的 before/after（本轮因工作树已改而缺失）。
6. **系统字体缩放**：用 125% / 150% 浏览器字号实测首页、学习中心、笔记、聊天、应用中心，确认标题换行、按钮不裁切。
7. **Network 断言**：补一轮 App 安装 / 停用 / 排序的 HTTP 200/400 断言（Playwright `page.waitForResponse`），避免只靠 UI 状态推断。
8. **深色逐页走查**：目前只覆盖 `/`、`/apps`、`/chat`、`/notes`；建议补齐 `/check-in`、`/habits`、`/learning/report` 的深色截图。

## P2 — 能力增强（需另立任务）

9. **用户级快捷栏配置**：固定 3 + 更多已可用；若要做「自定义固定 / 隐藏 / 排序」，先确认现有用户偏好存储（避免新建第二套菜单后端）。
10. **顶部任务 Popover**：目前只做路由跳转。若要做待办预览 + 快速新增，必须复用真实任务接口，并确认不重复提交。
11. **签到 / 习惯的顶栏轻面板**：当前跳转页面（符合「不自动签到、不重复打卡」合同）。若做面板，需复用 `checkinApi` / 习惯接口的幂等语义。
12. **番茄钟入口**：`/learning/pomodoro` 已在「更多快捷操作」中；若用户高频使用，可评估把它升为第 4 个常驻图标（≥1440 才显示，避免 1280 拥挤）。
