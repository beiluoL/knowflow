# Phase UI-2 · 导航命名对照表（Navigation Naming）

> 生成日期：2026-08-30
> 原则：**功能一个不少，只统一入口与叫法**（§8）。所有改名仅作用于导航展示层与浏览器标题，**未改动任何 URL**。

## 一、顶级导航改名

| 旧名称 | 新名称 | 原因 |
|---|---|---|
| 首页 | **首页**（不变） | 语义清晰，保留 |
| 学习工作台 | **学习**（并入二级） | 原本既是顶级入口、又出现在「学习」下拉里，重复（详见 §三）。改为「学习 › 学习工作台」单入口 |
| 知识库▾ | **知识** | 「知识库」既是顶级名、又是二级项名，同名造成层级混乱。顶级改为更宽泛的「知识」，「知识库」降为二级项 |
| 学习▾ | **学习**（不变） | 已符合用户任务语言 |
| 社区▾ | **社区**（不变） | 无歧义 |
| AI 助手▾ | **AI** | 顶级用短词，二级再用完整名（智能问答/编程 Agent/智能写作） |
| 成长▾ | **我的**（并入） | 「成长」是产品内部概念，用户不会说"我要去成长"。其内容（任务/打卡/成就）本就属于"我的"，并入后顶级从 8 降到 6 |
| 我的▾ | **我的**（不变） | 承接原「成长」内容 |

**净效果：8 个顶级 → 6 个顶级。**

## 四、品牌与页面标题

| 项 | 修改前 | 修改后 | 原因 |

| C 端 Logo 文案 | 「知识库」 | **「KnowFlow」** | 与后台侧栏一致（§22）；原来用户看到站点名叫"知识库"，与导航里的"知识库"菜单重名 |

## 五、刻意**不改**的项（避免风险）

| 项 | 决定 | 原因 |
|---|---|---|
| 所有 URL / path | **不改** | URL 可能已被书签、外链、前端代码引用（§41）。本阶段仅重组导航归属，0 处 URL 变更，因此无需新增重定向 |
| 文件名 `LearningCenter.vue` / `LearningReport.vue` | **不改** | 重命名会波及 import 与构建；导航层已统一叫法，文件重命名建议后续专项处理 |
| 「任务中心」与「任务清单」 | **不合并** | 二者是不同视图（聚合中心 vs 清单管理），合并会丢失功能 |
| `/notes` 与 `/workbench/notes` | **不合并** | 概念不同（普通笔记 vs 康奈尔笔记），Phase 0 已确认不合并 |
| 社区英文 `Community` | 保留中文「社区」 | 导航统一中文，无英文混用 |
