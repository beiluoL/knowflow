# Architecture-5 · Home UX（学习驾驶舱首页）

> 日期：2026-08-30。目标（§280）：用户打开首页第一眼就知道「我现在该做什么、为什么、下一步是什么」，
> 而不是「KnowFlow 有很多功能」。

## 1. 首页信息架构（§3/§58）

```
Home
│
├── 欢迎横幅（问候 + 主 CTA + 连击 / Coin / XP 轻量展示 §62）
│
├── 今日学习状态（§215-216）：今日任务 X/Y · 待复习 X · 薄弱 X · 当前路径 XX%
│     └── 今日奖励 +X XP · +Y Coin（reward_ledger 真实数据 §35-38）
│
├── 下一步（第一视觉 §5/§28/§118）—— NextActionCard（Resolver 驱动）
│
├── 今日任务（tasks 真实数据，可勾选完成）
│
├── 待复习 + 薄弱知识（并排：ReviewDueCard / WeakPointCard，§23：Home 只显示数量）
│
├── 当前学习路径（真实 enrolled 路径 + 后端 progress，§57）
│
├── 我的应用（已安装启用前 6 个，§162）
│
└── 继续学习（最近文档，次级）
```

**信息优先级（§58）**：下一步 > 今日任务 > 待复习 > 薄弱知识 > 当前路径 > 我的应用。
**学习 > 奖励 > 商城（§60）**：Coin/XP 只在横幅轻量展示，不喧宾夺主（§61-63）。

## 2. 本阶段删除了什么（§53-56/§281-286：减少选择、减少统计）

| 原区块 | 问题 | 处理 |
| --- | --- | --- |
| 「今日学习进度」三卡（课程进度环/连续天数卡/掌握度卡） | 课程进度 `readDocs/(readDocs+5)`、周目标 `weekTarget=14` 均为**伪造公式**（§15-16） | 整块删除，由「今日学习状态」真实汇总替代；连击并入横幅 |
| 「本周学习目标」环形进度（`weekDone = totalStudyHours % 14`） | 伪造周目标 | 删除 |
| 「为你推荐」路径横向滚动（N+1 拉章节进度） | 非数据驱动、重复统计 | 改为「当前学习路径」单卡（用后端已填充的 progress，去 N+1 §48） |
| 「推荐学习」静态 4 卡（闪卡/代码/文档/AI） | 静态入口、重复导航（§59） | 删除 |
| 继续学习卡片的「进度 %」 | `docProgress()` 恒返回 0（伪造 §82） | 删除进度显示，仅保留时间与分类 |
| 横幅「学习小时/篇文档」 | 虚荣统计（§55） | 删除，保留连击 + Coin + XP |

## 3. 下一步（第一视觉，§5-8/§28-32）

- 唯一来源：`learning/action-priority.ts` 的 `resolveNextAction()`（§6-7/§46），与 LearningCenter 共用（§11）；
- 主 CTA（横幅按钮）与「下一步」卡片由同一个 `actionToCta()` 驱动（§8/§108），杜绝「Home 一套、学习中心一套」（§10）；
- 文案示例（真实数据，§28-32）：复习 AQS / 完成今日任务 / 巩固 CAS / 继续 Java 并发路径 / 继续探索知识。

## 4. 今日学习状态（§215-216）

四个真实指标：今日任务完成数（`GET /learning/tasks`）、待复习（`GET /learning/mastery/review-required`）、
薄弱知识（`GET /learning/mastery/weak`）、当前路径进度（`GET /learning/paths` 的 enrolled+progress）。
**全部并行加载（§47/§126），任一失败不影响其它区块（§208）。**

## 5. 今日奖励（§35-40）

- 数据源：`GET /wallet/ledger`（reward_ledger 真源），按 `direction=CREDIT && 今天` 聚合（§38）；
- **绝不前端累加**（§40）：只读后端流水；
- 无数据/失败时静默隐藏（§211），不显示伪造的 0（§82）。

## 6. 加载 / 错误 / 空态（§49-52/§206-209）

- 无全局 loading 文本堆叠：各卡片自带 Skeleton（ReviewDueCard/WeakPointCard）；
- 独立错误隔离 + 重试（ErrorState）；空态走 EmptyState；
- 下一步失败降级为「继续探索知识」（§209/§250），绝不出现 undefined。

## 7. Mobile / Dark / A11y（§117-125）

- 390/768px：「下一步」位于首屏（§118-119）；状态网格 2 列；按钮 ≥ 44px 触控目标；
- 全部走 `--kb-*` 令牌（§192-197），明暗主题自适应；
- 语义化按钮 + aria-label + 焦点环；状态不只依赖颜色（§125）。

## 8. 与其它页面的分工（§24/§71-77）

| 页面 | 回答 |
| --- | --- |
| Home | 我现在该干什么？（决策） |
| Learning Center | 我今天怎么学？（计划：具体知识点） |
| App Center | 我需要什么能力？（获取） |
| Mini App | 我现在具体做什么？（行动） |
| 完成面板 | 我刚完成了什么？（结果+奖励+下一步） |
