# knowflow · AI Knowledge & Learning Platform

**A Java + Vue learning platform connecting knowledge management, RAG Q&A, spaced repetition and a coding agent.**

[Features](README.md#功能特性) · [Technology](README.md#技术栈)

- Collaborative knowledge bases, source citations and multi-model chat.
- Learning paths, SM-2 spaced repetition, flashcards, quizzes and coding exercises.
- Coding agent, tool calling, a ReAct loop and tool authorization.

**Technology / topics:** Java · Spring Boot · Spring Security · Vue 3 · TypeScript · MySQL
