React 18 并发模式详解

React 18 引入了全新的并发渲染机制，这是 React 架构演进中最重要的一次更新。并发模式让 React 能够在渲染过程中"中断"和"恢复"，从而更好地处理高优先级更新。

1. 什么是并发模式

并发模式是 React 18 的一组新功能，主要包括：

  • Automatic Batching - 自动批处理更新
  • Transitions API - 低优先级更新标记
  • Suspense - 组件级加载状态管理
  • useTransition - 过渡更新 Hook
  • useDeferredValue - 延迟值 Hook

2. useTransition Hook

useTransition 允许你将状态更新标记为"过渡"（非紧急），React 会在处理完紧急更新后再处理这些过渡更新。

import { useState, useTransition } from 'react';

function SearchComponent() {
  const [isPending, startTransition] = useTransition();
  const [searchQuery, setSearchQuery] = useState('');
  const [results, setResults] = useState([]);

  const handleChange = (e) => {
    const value = e.target.value;
    // 紧急更新：立即更新输入框
    setSearchQuery(value);
    // 非紧急更新：搜索结果可以延迟
    startTransition(() => {
      const filtered = filterResults(value);
      setResults(filtered);
    });
  };

  return (
    <div>
      <input value={searchQuery} onChange={handleChange} />
      {isPending && <p>搜索中...</p>}
      <ResultList results={results} />
    </div>
  );
}

3. Suspense 的增强

React 18 中 Suspense 支持了服务器端渲染的流式传输，并且可以在 Concurrent Mode 下实现更好的加载体验。

import { Suspense } from 'react';

function App() {
  return (
    <Suspense fallback={<LoadingSpinner />}>
      <UserProfile />
    </Suspense>
  );
}

4. useDeferredValue

useDeferredValue 用于延迟更新 UI 的某部分，常用于搜索输入等场景。

import { useState, useDeferredValue } from 'react';

function SearchPage() {
  const [query, setQuery] = useState('');
  const deferredQuery = useDeferredValue(query);

  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      <SearchResults query={deferredQuery} />
    </div>
  );
}

5. 关键要点总结

  1. 并发模式是渐进式增强的，不需要重写现有代码
  2. 使用 startTransition 标记非紧急更新，保持 UI 响应性
  3. Suspense 可以优雅地处理加载状态，支持流式 SSR
  4. useDeferredValue 适合延迟重渲染场景
  5. 配合 React.lazy 实现代码分割与按需加载
