Transformer 架构详解

张明教授
2025-12-15
Transformer, 深度学习, NLP, 注意力机制
12,845 次阅读

概述

Transformer 是由 Google Brain 团队在 2017 年论文《Attention Is All You Need》中提出的一种全新的深度学习架构。与传统的循环神经网络（RNN）和长短期记忆网络（LSTM）不同，Transformer 完全基于自注意力机制（Self-Attention）来处理序列数据，彻底抛弃了递归结构。这一革新性设计使其在自然语言处理、计算机视觉等多个领域取得了突破性进展，成为当前大语言模型（如 GPT、BERT）的基础架构。

自注意力机制

自注意力机制是 Transformer 的核心组件。它的核心思想是让序列中的每个位置都能够直接关注到序列中的所有其他位置，从而捕获长距离的依赖关系。在传统的 RNN 中，信息需要经过逐步传递才能到达远端位置，而自注意力机制通过并行计算所有位置之间的关联度，大幅提高了计算效率。

自注意力的计算过程可以概括为以下三个步骤：

  1. 计算 Query、Key、Value：对于输入序列中的每个 token，通过三个不同的线性变换生成对应的 Query (Q)、Key (K) 和 Value (V) 向量。
  2. 注意力分数计算：使用 Q 和 K 的点积来计算注意力分数，然后通过 softmax 函数归一化，得到每个位置对其他位置的注意力权重。
  3. 加权求和：使用注意力权重对 V 进行加权求和，得到最终的注意力输出。

自注意力的关键优势在于它可以直接建模任意两个位置之间的关系，不受距离限制。这使得 Transformer 能够更好地处理长序列和复杂依赖。

多头注意力

多头注意力（Multi-Head Attention）是对自注意力机制的扩展。它通过将注意力空间划分为多个"头"，让模型能够同时关注不同位置的不同表示子空间中的信息。每个头独立计算注意力，然后将所有头的输出拼接起来，再通过一个线性变换得到最终结果。

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, q, k, v, mask=None):
        B, N, _ = q.shape
        q = self.W_q(q).view(B, N, self.n_heads, self.d_k).transpose(1, 2)
        k = self.W_k(k).view(B, N, self.n_heads, self.d_k).transpose(1, 2)
        v = self.W_v(v).view(B, N, self.n_heads, self.d_k).transpose(1, 2)
        attn = (q @ k.transpose(-2, -1)) / math.sqrt(self.d_k)
        if mask is not None:
            attn = attn.masked_fill(mask == 0, float('-inf'))
        attn = F.softmax(attn, dim=-1)
        out = (attn @ v).transpose(1, 2).reshape(B, N, -1)
        return self.W_o(out)

多头注意力的优势在于不同的头可以学习到不同类型的关系模式。例如，有的头可能专注于语法关系，有的头可能专注于语义相似性，还有的头可能捕捉位置关系。这种多样化的注意力模式使模型能够更全面地理解输入序列。

位置编码

由于 Transformer 不包含递归或卷积结构，模型本身无法感知输入序列中 token 的位置顺序。为了解决这个问题，Transformer 引入了位置编码（Positional Encoding），将位置信息注入到输入嵌入中。原始 Transformer 使用正弦和余弦函数来生成位置编码：

# 位置编码公式
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

# 其中 pos 表示位置，i 表示维度

这种编码方式有几个重要特点：每个位置的编码是唯一的，不同位置之间的距离可以通过向量运算来表示，而且模型可以轻松泛化到比训练序列更长的序列上。后续的研究也探索了可学习的位置编码（如在 GPT 和 BERT 中使用的方法），以及相对位置编码等变体。

Transformer 整体架构

完整的 Transformer 由编码器（Encoder）和解码器（Decoder）两部分组成。编码器负责将输入序列映射为连续的表示，解码器则基于编码器的输出逐步生成目标序列。

  • 编码器：由 N 个相同的层堆叠而成（原论文中 N=6）。每层包含一个多头自注意力子层和一个前馈神经网络子层，每个子层都使用残差连接和层归一化。
  • 解码器：同样由 N 个相同的层堆叠而成。与编码器不同，解码器额外包含一个编码器-解码器注意力子层，用于关注编码器的输出。此外，解码器的自注意力子层使用了因果掩码（causal mask），确保每个位置只能关注到它之前的位置。
  • 前馈网络：每层中的位置全连接前馈网络由两个线性变换和一个 ReLU 激活函数组成。虽然结构简单，但它为模型提供了非线性变换能力。

Transformer 架构的一个关键设计原则是残差连接。每个子层的输出都被加上子层的输入，然后再进行层归一化。这种设计不仅有助于梯度传播，还使得深层网络的训练变得更加稳定。

应用与发展

Transformer 架构的出现彻底改变了深度学习的格局。基于 Transformer 的预训练语言模型如 BERT、GPT 系列已经在各类 NLP 任务上取得了卓越表现。近年来，Transformer 的应用范围还在不断扩大，已经延伸到计算机视觉（Vision Transformer）、语音识别、蛋白质结构预测等众多领域。

展望未来，Transformer 的研究方向包括：如何更高效地处理超长序列（如 Linear Attention、Ring Attention）、如何降低计算复杂度、以及如何更好地与结构化知识结合等。这些研究方向将推动 Transformer 在更多领域的应用，进一步释放其巨大的潜力。
