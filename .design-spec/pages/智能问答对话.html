useState 的实现原理

useState 是 React Hooks 中最基础的一个，它的核心原理是利用闭包和链表来维护组件的状态。

  1. React 内部使用一个 Fiber 链表来存储每个组件的 Hook
  2. 每次渲染时，Hook 按调用顺序依次读取链表节点
  3. 通过闭包捕获当前状态值和更新函数
const [state, setState] = useState(initialValue);
// state: 当前值
// setState: 更新函数（触发重新渲染）

那 useEffect 和 useState 有什么区别？useEffect 的执行时机是怎样的？

14:32

useState vs useEffect

  • useState：管理组件的状态，返回当前值和更新函数，是数据驱动
  • useEffect：处理副作用（DOM 操作、网络请求等），是行为驱动

useEffect 的执行时机：

  1. 组件首次渲染完成后执行
  2. 依赖数组中的值发生变化后执行
  3. 每次渲染后都会执行（无依赖数组时）

为什么 Hook 不能在条件语句中使用？

14:35

因为 React Hooks 依赖于调用顺序来正确关联状态。React 使用链表结构存储 Hook，每次渲染都按固定顺序遍历链表。

如果在条件语句中使用 Hook，渲染之间的 Hook 顺序可能不一致，导致状态混乱。

错误示例：if (condition) { useState(0); }

正确做法：在 Hook 内部做条件判断，而不是对 Hook 本身做条件判断。

useCallback 和 useMemo 有什么区别？什么时候用？

14:38

useCallback 缓存函数引用，useMemo 缓存计算结果。

  • useCallback：适合将回调函数传给子组件，避免子组件不必要的重渲染
  • useMemo：适合昂贵的计算，避免每次渲染都重新计算
