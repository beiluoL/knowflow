闭包（Closure）

闭包是指一个函数能够访问其词法作用域中的变量，即使该函数在其词法作用域之外执行。简单来说，闭包就是函数和其相关引用环境的组合。

function outer() {
  let count = 0;
  return function() {
    return ++count;
  }
}
