# 日历四类日期标记技术方案

> 2026-08-27 落地 · 知行合一 · 单一权威文档

## 一、需求与目标

在 KnowFlow 已有日历（月/周/日三视图，基于 Task 数据源）之上，准确且优雅地展示以下四类日期信息：

| 类别 | 含义 | 示例 |
| --- | --- | --- |
| 法定节假日 | 国务院办公厅每年公布的放假与调休安排 | 2026 年中秋 9/25-27 休、9/20 班 |
| 中国传统节日 | 按农历计算的民俗节日 | 中秋（农历八月十五）、端午（五月初五）、重阳（九月初九）、除夕、腊八等 |
| 现代节日 | 公历固定日期或按周计算（母亲节、父亲节、教师节等） | 教师节 9/10、母亲节 5 月第 2 个周日 |
| 纪念日 | 用户自定义，支持 fixed 固定日期与 yearly 每年重复 | 结婚纪念日 5/20（每年） |

**约束：**

- 各视图（月/周/日）用不同样式/颜色区分类别，信息清晰易读；
- 数据准确（含调休安排与农历换算），提供数据来源或算法说明；
- 界面风格简洁优雅，符合 Apple 设计语言与滴答清单排版习惯；
- 用户可在设置中添加、编辑纪念日；
- 合理的默认配色与标签，且视图间切换数据一致。

## 二、数据来源与算法

### 2.1 法定节假日（休/班）

**来源**：国务院办公厅《关于 202X 年部分节假日安排的通知》，原始发布在 **中国政府网（www.gov.cn）** 与新华社、人民日报转载。

**数据形式**（`CalendarMarkServiceImpl.HOLIDAY_RULES`）：

```java
private static final Map<Integer, List<HolidayRule>> HOLIDAY_RULES = new HashMap<>();
// HolidayRule{ LocalDate start, end, boolean rest, String name }
// rest=true 即放假（subLabel="休"），rest=false 即调休上班（subLabel="班"）
```

当前内置 **2025、2026** 两年数据，节假日放假与调休日期与国务院公告一致。每年新通知发布后追加对应年份规则即可。

**生成规则**（对区间内每一天）：

1. 未命中规则：周末（周六/周日）→ subLabel="休"（name="周末"）；工作日 → 不生成 holiday 标记（前端不显示角标）；
2. 命中 `rest=true`：subLabel="休"，name 来自规则（"春节"/"清明节"/"劳动节"/"端午节"/"中秋节"/"国庆节" 等）；
3. 命中 `rest=false`：subLabel="班"，name="调休上班"。

### 2.2 中国传统节日（农历）

**算法**：`util/LunarCalendar` 提供 **公历 ↔ 农历** 换算，采用公开的「查表法」。

- 数据表 `LUNAR_INFO[201]`：编码 1900-2100 每一年的农历信息（闰月月份 4bit + 12 个月大小月 12bit + 闰月大小 1bit），源自香港天文台推算数据，与 `lunar-javascript`、`sxtwl` 等主流农历库保持一致；
- `solarToLunar(LocalDate)` 与 `lunarToSolar(year, month, day, leap)` 双向换算；
- 完整测试用例覆盖：1990 / 2000 / 2023 / 2024 / 2025 / 2026 / 2027 春节（正月初一）、端午（五月初五）、中秋（八月十五）、除夕（腊月廿九或三十）、闰月（2025 闰六月、2023 闰二月）—— **20/20 全部通过**。

**传统节日映射**（`LunarCalendar.traditionalFestival`）：

| 农历月日 | 节日名 |
| --- | --- |
| 正月初一 | 春节 |
| 正月十五 | 元宵节 |
| 二月初二 | 龙抬头 |
| 五月初五 | 端午节 |
| 七月初七 | 七夕 |
| 七月十五 | 中元节 |
| 八月十五 | 中秋节 |
| 九月初九 | 重阳节 |
| 腊月初八 | 腊八节 |
| 腊月廿三 | 小年 |
| 腊月廿九/三十 | 除夕 |

**节气**（清明、冬至）：按公开通式近似计算 `d = ⌊Y * 0.2422 + C⌋ − ⌊Y / 4⌋`，其中清明 C=4.81、冬至 C=21.94（1900-2099 适用）。

### 2.3 现代节日（公历）

`CalendarMarkServiceImpl.MODERN_FESTIVALS` 内置 18 项，涵盖：

- **固定公历**：元旦 1/1、情人节 2/14、妇女节 3/8、植树节 3/12、愚人节 4/1、劳动节 5/1、青年节 5/4、儿童节 6/1、建党节 7/1、建军节 8/1、教师节 9/10、国庆节 10/1、万圣夜 10/31、平安夜 12/24、圣诞节 12/25；
- **按周计算**：母亲节（5 月第 2 个周日）、父亲节（6 月第 3 个周日）、感恩节（11 月第 4 个周四）；

**算法**（`nthDayOfMonth`）：根据年份 + 月份 + 第 n 个星期几计算具体日期，不存在则跳过（如 2 月第 5 个周一）。

### 2.4 纪念日

**表** `calendar_memorial`（H2 + MySQL 双 schema）：

```sql
CREATE TABLE IF NOT EXISTS calendar_memorial (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL,                   -- 逻辑外键 sys_user.id
  name VARCHAR(100) NOT NULL,                -- 纪念日名称
  type VARCHAR(10) NOT NULL,                 -- fixed 固定日期 / yearly 每年重复
  month_day VARCHAR(5) NOT NULL,             -- MM-dd（yearly 展开依据，fixed 冗余派生）
  fixed_date DATE,                           -- 完整 yyyy-MM-dd（fixed 专用）
  color VARCHAR(20),                         -- 标记颜色
  note VARCHAR(500),
  create_time / update_time / deleted        -- BaseEntity 标准字段
);
CREATE INDEX idx_cm_user ON calendar_memorial (user_id);
CREATE INDEX idx_cm_deleted ON calendar_memorial (deleted);  -- 索引名带表前缀以避免 H2 全局唯一冲突
```

**区间展开**：

- `fixed`：当 `fixed_date` 落在 [start, end] 内时生成标记；
- `yearly`：对区间内每一年，按 `month_day` 尝试匹配（处理跨年区间；2-29 等不存在的日期若不在 2020 等闰年自然命中，其它年份跳过）。

## 三、架构与接口

### 3.1 后端模块（Spring Boot 3）

新增文件清单：

| 路径 | 作用 |
| --- | --- |
| `entity/CalendarMemorial.java` | 纪念日实体（`@TableName("calendar_memorial")`） |
| `mapper/CalendarMemorialMapper.java` | MyBatis-Plus `BaseMapper<CalendarMemorial>` |
| `dto/MemorialDTO.java` | 纪念日新增/更新入参 |
| `vo/MemorialVO.java` | 纪念日视图对象 |
| `vo/DateMarkVO.java` | 日期标记视图对象（4 类共用） |
| `util/LunarCalendar.java` | 公历 ↔ 农历换算工具（1900-2100） |
| `service/CalendarMarkService.java` | 业务接口 |
| `service/impl/CalendarMarkServiceImpl.java` | 业务实现（节假日/农历/现代/纪念日） |
| `controller/CalendarMarkController.java` | `/api/calendar` REST 控制器 |
| `db/h2/schema.sql` / `db/mysql/schema.sql` | `calendar_memorial` 表与索引（H2 索引带 `idx_cm_` 前缀） |

### 3.2 REST API

```
GET    /api/calendar/marks?start=yyyy-MM-dd&end=yyyy-MM-dd
POST   /api/calendar/memorials
GET    /api/calendar/memorials
PUT    /api/calendar/memorials/{id}
DELETE /api/calendar/memorials/{id}
```

- 全部需登录，按 `user_id` 维度隔离（纪念日 CRUD）。
- `marks` 接口跨 4 类数据合并，按 date 升序、type 稳定排序返回；区间上限 730 天（约 2 年）。
- `DateMarkVO`：`{ type, date, name, subLabel, color, memorialId }`；
  - `type ∈ { holiday, lunar, modern, memorial }`；
  - `subLabel` 在 `holiday` 时为 `"休"`/`"班"`，在 `lunar` 时为农历月日（如「八月十五」）；
  - `color` 由后端统一给出，前端不另行硬编码。

### 3.3 前端模块（Vue3 + TS + Vite）

| 路径 | 作用 |
| --- | --- |
| `api/calendar.ts` | 扩展 `DateMark`/`Memorial` 类型与 CRUD/listMarks 接口；导出 `MARK_COLORS` 主题色常量 |
| `stores/calendar.ts` | 新增 `marks` 状态；`loadRange()` 中 `Promise.all([events, marks])` 并行加载，保证数据同源一致 |
| `components/calendar/MonthView.vue` | 月视图：日期旁「休/班」徽章 + 节日标签（最多 2 条 +N） |
| `components/calendar/TimeGridView.vue` | 周/日视图：日期头部下方展示「休/班」徽章 + 节日标签（周视图最多 2 条 / 日视图最多 5 条） |
| `components/calendar/MemorialDialog.vue` | 纪念日管理弹窗（列表 + 表单，fixed/yearly 切换，8 色预设板，删除走 `dialog.confirm danger`） |
| `views/CalendarView.vue` | 头部加「纪念日」入口；工具栏下加图例；传 `marks` 给子视图 |

## 四、视觉与交互

### 4.1 配色（与 Apple 日历 + 滴答清单对齐）

| 类别 | 颜色 | 用途 |
| --- | --- | --- |
| 法定节假日 休 | `#E5484D` 红 | 红底白字小徽章「休」 |
| 法定节假日 班 | `#F59E0B` 橙 | 橙底白字小徽章「班」 |
| 中国传统节日 | `#E11D48` 玫红 | 小圆点 + 名称文字（subLabel 显示农历月日） |
| 现代节日 | `#0EA5E9` 蓝 | 小圆点 + 名称文字 |
| 纪念日 | `#8B5CF6` 紫（可自定义） | 小圆点 + 名称文字，鼠标悬停显示完整日期 |

前端不重复硬编码颜色——`MARK_COLORS` 常量与后端常量一一对应，修改时同步。

### 4.2 月视图

- 格子顶部：日期数字 + 「休/班」徽章；
- 节日标签行（紧贴日期下方，最多 2 条，超过显示 `+N`）；
- 事件 chips 行（保留原有，3 条 + `+N 更多`）；
- 三类信息层次清晰，互不挤占。

### 4.3 周/日视图

- 日期头部新增节日行：`周X / 日期数字 / 「休/班」徽章 / 节日标签行`；
- 周视图每列最多 2 条节日 + `+N`，日视图每列最多 5 条；
- 全天/定时事件区保留原行为。

### 4.4 纪念日弹窗

- 列表视图：左侧色点、名称、日期范围、类型、备注；右侧编辑/删除按钮；
- 表单视图：名称 / 类型切换（每年重复 / 固定日期）/ 日期输入（month+day 双 select 或 date picker）/ 8 色预设 / 备注；
- 删除走 `utils/dialog.ts` 的 `dialog.confirm({ variant: 'danger' })`，**禁止浏览器原生 confirm/alert/prompt**；
- 保存/删除后 `emit('changed')`，CalendarView 触发 `store.loadRange()` 刷新。

## 六、扩展指南

- **新增法定节假日规则**：在 `CalendarMarkServiceImpl.HOLIDAY_RULES` 的 `static {}` 块追加 `rules(2027, rest(...), work(...), ...)` 即可，每年通知发布后立即生效；
- **新增现代节日**：在 `MODERN_FESTIVALS` 追加 `ModernFestival.fixed(11, 11, "光棍节")` 或 `ModernFestival.nth(11, 4, DayOfWeek.FRIDAY, "黑色星期五")`；
- **新增农历节日**：在 `LunarCalendar.traditionalFestival` 添加分支即可（基于农历月日 + 是否闰月）。
